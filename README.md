Project: Code Change Impact Analyzer 
Concepts: code embeddings, RAG, LLM code analysis.
## 📌 Project Overview

**Code-Change-Impact-Analyzer** is a web application that analyzes code changes and helps developers understand which parts of a software project may be affected by a modification.

The system provides an easy-to-use interface where users can provide code changes and receive an analysis of the possible impact, affected components, dependencies, and potential risks.

## 🎯 Objectives

* Analyze the impact of code changes.
* Identify potentially affected files or components.
* Understand dependencies between code components.
* Help developers detect possible risks before applying changes.
* Provide analysis through a simple web interface.
